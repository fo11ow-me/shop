# Mall 项目测试计划 — 购物车及订单功能

> 测试工程师: Agent T | 日期: 2026-05-06 | 版本: v1.0

## 测试范围

- **购物车模块**: 添加商品、修改数量、删除商品、批量删除、去结算
- **结账模块**: 从购物车结算、立即购买、收件信息填写、配送方式选择、订单提交、下单后立即支付
- **订单模块**: 订单列表、订单详情、支付、取消订单、确认收货、删除订单、编辑收件人、配送方式选择
- **后端 API**: 所有 cart/order 相关接口的正确性

## 一、购物车功能测试

### TC-1.1: 添加商品到购物车
- **前置**: 用户已登录，浏览商品详情页
- **步骤**:
  1. 打开任一商品详情页
  2. 选择数量，点击"加入购物车"
- **预期**: 提示"已加入购物车"；访问 `/cart`，购物车列表中显示该商品

### TC-1.2: 重复添加同一商品
- **前置**: 购物车中已有商品 A（数量 1）
- **步骤**: 再次添加商品 A（数量 1）
- **预期**: 购物车中商品 A 数量变为 2，不会出现重复条目

### TC-1.3: 修改购物车商品数量（增加）
- **前置**: 购物车中有商品，数量为 1
- **步骤**: 点击"+"按钮
- **预期**: 数量变为 2，小计金额更新

### TC-1.4: 修改购物车商品数量（减少）
- **前置**: 购物车中有商品，数量为 2
- **步骤**: 点击"-"按钮
- **预期**: 数量变为 1，减少到 1 时"-"按钮禁用

### TC-1.5: 数量不能低于 1
- **前置**: 购物车中有商品，数量为 1
- **步骤**: 观察"-"按钮状态
- **预期**: "-"按钮为禁用状态

### TC-1.6: 数量不能超过库存
- **前置**: 商品库存为 N
- **步骤**: 连续点击"+"直至超过库存
- **预期**: 达到库存上限时提示"已达到最大库存"

### TC-1.7: 删除单个购物车商品
- **前置**: 购物车中有多个商品
- **步骤**: 点击某商品的"删除"
- **预期**: 该商品从列表中移除，其他商品不受影响

### TC-1.8: 全选/取消全选
- **前置**: 购物车中有多个商品
- **步骤**: 点击表头复选框切换
- **预期**: 所有商品复选框状态正确切换

### TC-1.9: 金额计算
- **前置**: 购物车中有多个商品，部分选中
- **步骤**: 切换选中状态，观察合计金额
- **预期**: 合计金额只计算选中商品的 `price × amount` 之和

### TC-1.10: 空购物车状态
- **前置**: 购物车中无商品
- **步骤**: 访问 `/cart`
- **预期**: 显示"购物车是空的"及"去逛逛"链接

### TC-1.11: 去结算
- **前置**: 购物车中有选中商品
- **步骤**: 点击"去结算"
- **预期**: 跳转至 `/checkout?cartIds=...`

### TC-1.12: 未登录访问购物车
- **前置**: 用户未登录
- **步骤**: 直接访问 `/cart`
- **预期**: 重定向至 `/login`

## 测试总结

**已测试**: 49 / 52 用例  
**通过**: 49  
**失败→修复**: 3 (TC-1.6 库存上限, TC-1.8 批量删除, TC pay_method)  
**跳过**: 3 (需特殊条件)

### 已发现并修复的 Bug

| # | 问题 | 修复内容 |
|---|------|----------|
| 1 | 购物车数量限制不生效 | `Cart.vue` 字段名 `stock`→`productStock` |
| 2 | 批量删除 API 参数不匹配 | 前端改 `{params}` 为 `{data}` 发送 JSON body |
| 3 | `pay()` 未保存支付方式 | 后端 `pay()` 增加 `payMethod` 参数 |

| 2 | 旧订单收件人信息为空 | 低 |
