# 售后政策

## 退换货规则
- 支持7天无理由退货，自签收之日起7天内可申请。
- 15天内出现质量问题可免费换货。
- 退货商品需保持原包装完整，配件齐全，不影响二次销售。
- 以下商品不支持无理由退货：已拆封的数码产品、内衣、化妆品、食品。

## 退款流程
1. 用户提交退货申请，填写退货原因。
2. 客服审核通过后，用户将商品寄回指定地址。
3. 仓库收到退货并验收合格后，3个工作日内原路退款。
4. 退款金额为实际支付金额，使用优惠券的部分不退还现金。

## 保修政策
- 电子产品享有一年质保，自购买之日起计算。
- 保修期内非人为损坏免费维修，人为损坏收取配件成本费。
- 超过保修期的商品可付费维修，具体费用以维修师傅报价为准。
