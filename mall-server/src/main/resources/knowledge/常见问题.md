# 常见问题

## 账号相关
- 忘记密码：在登录页点击"忘记密码"，通过手机验证码重置密码。
- 修改手机号：登录后在个人信息页面修改，需验证当前手机号。
- 账号注销：联系客服申请注销，注销后所有数据将被清除且不可恢复。

## 订单相关
- 下单后如何修改地址：未发货的订单可在订单详情页修改收货地址；已发货的订单需联系客服。
- 如何取消订单：待支付状态的订单可直接取消；已支付未发货的订单需联系客服取消。
- 订单超时：下单后30分钟内未支付，订单将自动取消。
- 重复下单：如误操作重复下单，可取消多余订单，系统不会重复扣款。

## 商品相关
- 商品价格是否含税：所有标价均为含税价格。
- 商品库存显示：页面显示的库存为实时库存，加入购物车后不锁定库存，以提交订单时为准。
- 商品颜色/尺码选择：详情页可选择颜色和尺码，选中后图片会对应切换。
- 商品缺货：如遇缺货，系统会自动通知并建议替代商品。

## 其他
- 积分规则：每消费1元累积1积分，100积分可抵扣1元。
- 优惠券使用：每笔订单限用一张优惠券，不可与其他优惠叠加（满减除外）。
- APP下载：商城提供iOS和Android客户端，可在应用商店搜索"mall商城"下载。
