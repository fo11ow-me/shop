# 支付方式

## 支持的支付方式
- 微信支付
- 支付宝
- 银行卡（借记卡和信用卡均支持）
- Apple Pay（iOS端可用）

## 支付限额
- 微信支付单笔限额：5000元
- 支付宝单笔限额：10000元
- 银行卡支付限额以发卡行规定为准
- 大额订单建议使用银行卡或支付宝支付

## 支付安全
- 所有支付均通过加密通道传输，保障资金安全。
- 支付密码不会存储在商城服务器。
- 如遇支付异常（扣款但订单未生成），系统会在2小时内自动退款。

## 发票说明
- 支持开具电子发票和纸质发票。
- 电子发票在确认收货后自动发送至注册邮箱。
- 纸质发票随包裹寄出，需在下单时勾选"需要发票"。
- 发票抬头支持个人和公司，公司发票需提供税号。
