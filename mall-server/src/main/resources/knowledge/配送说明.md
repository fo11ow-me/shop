# 配送说明

## 配送方式
- 默认合作快递：顺丰速运、京东物流、中通快递。
- 下单时可选择快递公司，不同快递运费可能不同。
- 部分偏远地区（新疆、西藏、内蒙古等）可能需要额外加收运费。

## 配送时效
- 一线城市（北上广深）：下单后1-2天送达。
- 省会城市：下单后2-3天送达。
- 其他城市：下单后3-5天送达。
- 偏远地区：下单后5-7天送达。

## 包邮政策
- 订单满599元全国包邮（偏远地区除外）。
- 促销活动期间可能有额外的包邮门槛降低或全店包邮。
- 秒杀商品不参与包邮，需单独支付运费。

## 物流查询
- 发货后系统会推送物流单号到订单详情页。
- 可通过订单详情页的物流跟踪查看包裹实时位置。
- 如超过预计时效未收到包裹，请联系客服处理。
